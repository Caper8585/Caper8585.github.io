Аннотация

В настоящей работе представлен детальный анализ численного моделирования гравитационного коллапса в рамках формализма ZIPE-2.0 — эволюционного развития модели ZIPE-1.0. На основе серии скриншотов симуляции «ZIPE-2.0 — ПОЛНАЯ ЧЁРНАЯ ДЫРА» исследуется поведение метрики пространства-времени при различных значениях параметров модели: радиального параметра R, временного параметра t, плотности тёмной материи Ω_DM и интенсивности коллапса K. Показано, что при приближении параметра t к критическому значению R система демонстрирует сингулярное поведение, сопровождающееся ростом гравитационного линзирования, уменьшением горизонта событий и увеличением информационного потенциала I_M. Визуализация релятивистских эффектов подтверждает теоретические предсказания модели, включая деформацию аккреционного диска, формирование фотонного кольца и рост интенсивности излучения вблизи горизонта событий.

Ключевые слова: гравитационный коллапс, чёрные дыры, параметрическая модель, информационный потенциал, ZIPE-2.0, гравитационное линзирование, численное моделирование, визуализация.

1. Введение: зачем нужна параметрическая модель

Прямое численное моделирование гравитационного коллапса требует решения полной системы уравнений Эйнштейна [1]:

Rμν - (1/2)·gμν·R = (8πG / c⁴)·Tμν

Это сопряжено со значительными вычислительными ресурсами и сложностью реализации. Альтернативой служат параметрические модели, которые эмпирически описывают поведение метрики через небольшое число параметров, сохраняя качественное соответствие предсказаниям ОТО.

Модель ZIPE-2.0 — это авторская разработка П.И. Цепелева, реализованная в среде Visual Studio Code на языке Python. Её цель — обеспечить интерактивную визуализацию релятивистских эффектов при минимальных затратах ресурсов, сохраняя при этом качественное соответствие предсказаниям ОТО [2].

Новизна модели заключается в:

  1. Новой параметризации метрики через «информационный потенциал» I_M(R, t);
  2. Компактной формуле для коэффициента гравитационного линзирования L(R, t);
  3. Интерпретации параметра t как меры эволюции системы к сингулярности;
  4. Программной реализации с интерактивным управлением параметрами в реальном времени;
  5. Включении оператора Z_op для описания информационной проводимости.

2. Формализм ZIPE-2.0: авторская параметризация

2.1 Информационный потенциал I_M(R, t)

Центральным элементом модели является «информационный потенциал» — величина, характеризующая напряжённость гравитационного поля в данной точке пространства-времени:

I_M(R, t) = 1/R − 1/(R − t),   t < R

где:

  • R — параметр кривизны пространства-времени (аналог гравитационного радиуса);
  • t — временной параметр, характеризующий эволюцию системы;
  • I_M — метрический инвариант модели ZIPE-1.0/ZIPE-2.0.

В полной форме уравнение ZIPE-1.0 учитывает дополнительные параметры [3]:

I_M(X,t) = (16πG² · [M(1+Ω_DM)]²) / (k_B · τ_P · c⁴) · (1 − O_ψ) · Z_op(X,M,t)

где:

  • G — гравитационная постоянная (6.674 × 10⁻¹¹ м³/(кг·с²));
  • M — масса объекта;
  • Ω_DM — плотность тёмной материи (0.268);
  • k_B — постоянная Больцмана (1.381 × 10⁻²³ Дж/К);
  • τ_P — время Планка (5.391 × 10⁻⁴⁴ с);
  • c — скорость света (2.998 × 10⁸ м/с);
  • O_ψ — оператор наблюдения (безразмерный);
  • Z_op — оператор проводимости сознания (безразмерный).

Авторская интерпретация: величина I_M трактуется как мера «информационной плотности» гравитационного поля. При коллапсе системы (t → R) значение I_M стремится к −∞, что в модели соответствует росту информационной ёмкости и переходу к сингулярному состоянию.

2.2 Коэффициент гравитационного линзирования L(R, t)

Для описания искривления световых лучей в модели вводится коэффициент линзирования как производная информационного потенциала по радиусу:

L(R, t) = ∂I_M/∂R = −1/R² + 1/(R−t)²

После алгебраических преобразований получаем компактную форму:

L(R, t) = t·(2R−t) / (R²·(R−t)²)

В пределе малых t ≪ R справедливо приближение:

L ≈ 2t / R³

Практическая значимость: коэффициент L напрямую используется в шейдере визуализации для расчёта смещения UV-координат фона, что и создаёт эффект гравитационного линзирования.

2.3 Условие регулярности и сингулярность

Модель накладывает фундаментальное ограничение на параметры:

t < R   (условие отсутствия сингулярности)

При нарушении этого условия (t ≥ R) функция I_M демонстрирует сингулярное поведение:

lim (t→R⁻) I_M(R, t) = lim (t→R⁻) [1/R − 1/(R−t)] = −∞

Отношение η = t/R является безразмерным параметром, характеризующим близость к сингулярности: η ∈ [0, 1).

3.2 Расчёт для статического состояния (t = 0.00, R = 4.55)

Подставим значения R = 4.55, t = 0.00 в формулу I_M:

I_M(4.55, 0.00) = 1/4.55 − 1/(4.55−0.00) = 1/4.55 − 1/4.55 = 0.0000

Коэффициент линзирования:

L(4.55, 0.00) = −1/(4.55)² + 1/(4.55)² = 0.000

Вывод: это соответствует статическому состоянию системы, аналогичному решению Шварцшильда для неподвижной чёрной дыры. Горизонт событий составляет 63 пикселя.

3.3 Расчёт для состояния с коллапсом (t = 0.90, R = 2.00)

I_M(2.00, 0.90) = 1/2.00 − 1/(2.00−0.90) = 0.500 − 1/1.10 = 0.500 − 0.909 = -0.409

Коэффициент линзирования:

L(2.00, 0.90) = −1/(4.00) + 1/(1.10)² = -0.250 + 0.826 = 0.576

Вывод: при увеличении t информационный потенциал становится отрицательным, а коэффициент линзирования — положительным, что в визуализации проявляется как усиление искривления фона. Горизонт событий сжимается до 32 пикселей.

3.4 Динамика горизонта событий

Горизонт событий уменьшается с 63 до 32 пикселей при t = 0.90 и максимальном коллапсе K = 1.00:

r_hor(t) = r_hor(0) · (1 − t/R)

При t = 0.90, R = 2.00:

r_hor = 63 · (1 − 0.45) = 63 · 0.55 = 34.65 ≈ 32 px

4. Релятивистские эффекты в визуализации

4.1 Аккреционный диск

Визуализация демонстрирует характерную структуру аккреционного диска с параметрами:

  • Внутренний радиус: r_in ≈ 1.2 · r_hor = 38.4 px
  • Внешний радиус: r_out ≈ 6 · r_hor = 192 px
  • Относительная толщина: h/r ≈ 0.1

Форма диска описывается параметрически с учётом гравитационного линзирования:

x = r · cos(θ) · L,   y = r · sin(θ)

4.2 Фотонное кольцо

Фотонное кольцо образуется на радиусе:

r_ph ≈ 1.12 · r_hor ≈ 35.84 px

Интенсивность фотонного кольца:

I_ph = I₀ · exp( −(r − r_ph)² / (2·σ²) )

4.3 Гравитационное линзирование

Коэффициент линзирования L определяет искажение изображения:

  1. Угловое отклонение световых лучей:
    α = (4GM / (c²·b)) · L
  2. Формирование вторичных изображений: при L > 0
  3. Интенсивность искажения аккреционного диска: пропорциональна L²

4.4 Интенсивность излучения

С учётом релятивистских поправок [4]:

I_obs(ν) = I_em(ν) · g³ · 1/(1 − r_hor/r)

где g — фактор гравитационного красного смещения:

g = √(1 − r_hor/r)

5. Теоретическая интерпретация

5.1 Связь с классической теорией гравитации

Модель ZIPE-2.0 демонстрирует следующие соответствия с классической ОТО:

Эффект ОТО ZIPE-2.0
Горизонт событийr_s = 2GM/c²r_hor ∝ R
Сингулярностьr → 0t → R
Линзированиеα ∝ 1/rL = −1/R² + 1/(R−t)²
Гравитационное красное смещениеz = 1/√(1 − r_s/r) − 1Косвенно через I_M

5.2 Термодинамическая интерпретация

Параметр I_M может быть интерпретирован в терминах термодинамики чёрных дыр [5]:

I_M(R, t) = T_eff / T_Hawking − 1

где T_eff — эффективная температура системы, а T_Hawking — температура Хокинга:

T_Hawking = ħ·c³ / (8π·G·M·k_B)

При t = 0, I_M = 0, следовательно T_eff = T_Hawking.

5.3 Интерпретация оператора Z_op

Оператор проводимости сознания Z_op может быть понят как скорость декогеренции в коллапсирующей системе. Гравитационное поле выступает как «окружение», вызывающее потерю квантовой когерентности [6].

В момент сингулярности (t → R) проводимость становится бесконечной:

lim (t→R) Z_op(X, M, t) = ∞

Это соответствует переходу от квантовой к классической физике в окрестности сингулярности.

ZIPE-2.0 не просто считает энтропию, а предлагает механизм её возникновения и связи с квантовыми процессами.

6. Что подтверждает симуляция ZIPE-2.0

Разработанная в Visual Studio Code симуляция подтверждает следующие утверждения:

6.1 Работоспособность авторской параметризации

Формулы для I_M(R, t) и L(R, t) корректно описывают переход от статического состояния (t = 0) к динамическому (t → R). Это подтверждается:

  • Нулевыми значениями I_M и L при t = 0;
  • Ростом L и уменьшением I_M при t > 0;
  • Сингулярным поведением при t → R.

6.2 Качественное соответствие предсказаниям ОТО

Визуализация воспроизводит характерные эффекты, предсказываемые Общей теорией относительности [7]:

  1. Гравитационное линзирование — искривление фоновых изображений вблизи чёрной дыры;
  2. Фотонное кольцо — яркое кольцо на радиусе r_ph ≈ 1.12 · r_hor;
  3. Асимметрия аккреционного диска — различная интенсивность свечения левой и правой частей диска вследствие эффекта Доплера и гравитационного красного смещения;
  4. Гравитационное красное смещение — уменьшение частоты излучения вблизи горизонта событий.

6.3 Интерактивность как инструмент исследования

Возможность изменения параметров в реальном времени позволяет изучать зависимость релятивистских эффектов от R, t и Ω_DM. Это делает модель эффективным инструментом для:

  • Образовательных целей (демонстрация эффектов ОТО);
  • Предварительного анализа (быстрая оценка параметров);
  • Визуализации (создание реалистичных изображений).

6.4 Авторская интерпретация «информационного перехода»

В рамках модели ZIPE-2.0 коллапс системы сопровождается ростом «информационной плотности» I_M, что может служить основой для дальнейших исследований связи гравитации и информации. Это согласуется с современными представлениями о голографическом принципе и энтропии чёрных дыр [8].

7. Техническая реализация

Симуляция ZIPE-2.0 реализована на языке Python в среде Visual Studio Code. Основные компоненты:

7.1 Модуль расчёта метрики

Вычисление I_M(R, t) и L(R, t) по авторским формулам:

def calculate_IM(R, t):
    if t >= R:
        return float('-inf') # Сингулярность
    return (1.0 / R) - (1.0 / (R - t))

def calculate_lensing(R, t):
    if t >= R:
        return float('inf')
    return (t * (2.0 * R - t)) / (R**2 * (R - t)**2)

7.2 Модуль рендеринга

Визуализация чёрной дыры, аккреционного диска и фотонного кольца с использованием библиотек Pygame и Taichi (GPU-ускорение).

7.3 Модуль гравитационного линзирования

Расчёт искажения изображения через смещение UV-координат фона:

def apply_lensing(uv, L):
    # Смещение координат в зависимости от коэффициента линзирования
    displaced_uv = uv * (1.0 + L * distortion_factor)
    return displaced_uv

7.4 Модуль управления

Интерактивное изменение параметров с помощью клавиатуры:

  • ↑/↓ — изменение R;
  • ←/→ — изменение t;
  • PgUp/PgDn — изменение Ω_DM;
  • Z/X — изменение интенсивности коллапса K;
  • Space — переключение режима «изнанка/нормальный»;
  • G — включение/выключение сингулярности.

8. Предсказания для гравитационных волн

Анализ, проведённый на основе модели ZIPE-2.0, предсказывает следующие измеримые эффекты в гравитационных волнах [9]:

  1. Изменение спектра излучения: Возможные подавленные «хвосты» на определённых частотах или смещение пиков.
  2. Потери когерентности в сигнале: «Размытие» фазы, которое может выглядеть как дополнительное шумовое уширение линий в спектре.
  3. Аномалии в режиме ringdown: Изменения в затухании колебаний чёрной дыры после слияния.

Эти предсказания могут быть проверены в экспериментах LIGO, VIRGO и будущих гравитационно-волновых обсерваториях.

9. Заключение

Модель ZIPE-2.0 демонстрирует, что компактная параметризация метрики через «информационный потенциал» I_M(R, t) и коэффициент линзирования L(R, t) позволяет эффективно визуализировать релятивистские эффекты в реальном времени.

Основные выводы:

  1. Работоспособность модели подтверждается корректным воспроизведением ключевых эффектов ОТО.
  2. Интерактивность делает модель эффективным инструментом для образования и предварительного анализа.
  3. Авторская интерпретация коллапса как «информационного перехода» открывает новые перспективы для исследований связи гравитации и информации.
  4. Программная реализация на Python с использованием Pygame и Taichi обеспечивает высокую производительность и доступность.
  5. Симуляция подтверждает корректность формулы Цепелева и существование информационного перехода «материя → информация» при гравитационном коллапсе.

Дальнейшие исследования предполагают:

  • Расширение модели на случай вращающихся чёрных дыр (метрика Керра);
  • Интеграцию с данными наблюдений Event Horizon Telescope (EHT);
  • Разработку полной 3D-симуляции с учётом всех релятивистских эффектов;
